# Medi Reminder — Android (Kotlin + Jetpack Compose)

Native Android port of the medicine reminder UI, built with Kotlin and Jetpack Compose (Material 3).

## Why this lives beside the React app
Figma Make only compiles and previews web apps (React + Vite), so the live preview
still runs the original `src/App.tsx`. This `android/` folder is a real, buildable
Android project — open it in Android Studio to run it on an emulator or device.

## Run it
1. Open the `android/` folder in **Android Studio** (Hedgehog or newer).
2. Let Gradle sync (downloads the Compose BOM + dependencies).
3. Pick an emulator / device and press **Run**.

Requires JDK 17. A Gradle wrapper (`gradlew`) is generated by Android Studio on first
open; alternatively run `gradle wrapper` if you have a local Gradle install.

## Structure
- `MainActivity.kt` — full screen: top bar, date strip, progress card, timeline schedule, Take toggles, bottom nav, add-medicine `ModalBottomSheet`.
- `Medicine.kt` — data models + seed data.
- `ui/theme/` — color tokens, typography, Material 3 theme.
